MEGAN’S MANICURES — FREE WEBSITE

FILES
- index.html: your responsive one-page website.

BEFORE PUBLISHING
1. Open index.html in a text editor.
2. Search for YOUR-EMAIL-HERE@example.com.
3. Replace it with the email address where you want appointment requests sent.
4. Save the file.
5. Optional: replace the example nail gallery image URLs with photos of your own work.

FREE PUBLISHING WITH GITHUB PAGES
1. Create/sign in to a free account at https://github.com/
2. Create a new public repository named megans-manicures (or another available name).
3. Upload index.html to the repository's top level.
4. Open the repository's Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch, select the main branch and /(root), then Save.
6. Wait a few minutes. GitHub will show the published website URL in Settings → Pages.

BOOKING NOTES
- This is a static site. The booking form validates required fields and opens the visitor's email app with a prefilled request; it does not automatically reserve a time or confirm availability.
- For a real online calendar with availability and automatic confirmations, connect a booking provider and replace the form's mailto flow with that provider's booking link/embed.
- Appointment requests should be confirmed by you before the customer visits your in-home studio.
